# fret-calculator
 
A REST API for guitar fret calculations, built with Clojure.
 
## Tech Stack
 
- **Language:** Clojure
- **Build tool:** Leiningen
- **Editor:** VSCode + Calva
## Requirements
 
- Java 25+
- Leiningen 2.12.0
## Getting Started
 
```bash
# Clone the repository
git clone https://github.com/SantiagoCMS/fret-calculator.git
cd fret-calculator
 
# Run the project
lein run
 
# Start the REPL
lein repl
```
 
## Project Structure
 
```
fret-calculator/
├── src/fret_calculator/core.clj            # Entry point
├── test/fret_calculator/core_test.clj      # Tests
└── project.clj                             # Dependencies and config
```
